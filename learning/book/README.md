# The book goes here, but is not committed

The curriculum in `learning/` follows *Learn Java for FTC* by Alan G. Smith. Put your copy of the
PDF (and the .docx if you have it) in this folder; Git ignores everything here except this file,
because the repo is public and the book is the author's copyright.

Get the book from the author: https://github.com/alan412/LearnJavaForFTC (free download).
