EXERCISE 1 — Switch to Autonomous  (★☆☆☆)
------------------------------------------------------
Change your OpMode from @TeleOp to @Autonomous.
Run it — does it appear in the Autonomous list on the
Driver Station instead of TeleOp? Switch it back when done.

HINT: Change the annotation at the top of the class.
      You'll also need to import Autonomous:
      import com.qualcomm.robotcore.eventloop.opmode.Autonomous;

------------------------------------------------------
EXERCISE 2 — Init Loop Countdown  (★★☆☆)
------------------------------------------------------
Add an init_loop() method that shows a countdown.
While the driver is waiting to press PLAY, display:
  "Ready to start? Press PLAY"
  "Seconds since INIT: [number]"

HINT: Add a method like this inside your class:
  @Override
  public void init_loop() {
      telemetry.addData("Ready to start?", "Press PLAY");
      telemetry.addData("Seconds since INIT", getRuntime());
  }

------------------------------------------------------
EXERCISE 3 — Formatted Runtime  (★★☆☆)
------------------------------------------------------
Display the runtime formatted to exactly 2 decimal places.
Instead of showing  "5.123456789"  it should show  "5.12"

HINT: Use a format string with telemetry.addData():
  telemetry.addData("Runtime", "%.2f sec", getRuntime());

The "%.2f" means: floating point number with 2 decimal places.

------------------------------------------------------
EXERCISE 4 — Different Message Each Second  (★★★☆)
------------------------------------------------------
Make the telemetry display alternate between two messages
once per second:
  - When runtime is 0-1 sec: show "Tick"
  - When runtime is 1-2 sec: show "Tock"
  - When runtime is 2-3 sec: show "Tick"
  - etc.

HINT: Use (int)getRuntime() to get the whole-number seconds,
then use % 2 (the modulo operator) to check if it's even or odd.
  if ((int)getRuntime() % 2 == 0) { ... } else { ... }

------------------------------------------------------
EXERCISE 5 — CHALLENGE: Stop Message  (★★★★)
------------------------------------------------------
Add a stop() method. When the driver presses STOP, send
the total runtime and the final loop count to telemetry,
then call telemetry.update() so the message actually shows.

NOTE: The stop() method only runs for a brief moment before
the OpMode shuts down, so you must call telemetry.update()
inside stop() or the message won't appear.
